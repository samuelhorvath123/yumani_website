# Yumani Automation design system

## Scene and direction
A business or institution leader opens the site on a laptop in a bright office, looking for a capable team that can make everyday work easier. The page should feel like soft morning light: clear, optimistic and calm.

## Palette
A light icy-blue environment, anchored with cobalt blue. All neutrals are tinted toward blue. Tokens live in app/globals.css and use OKLCH: background 0.985 / 0.005 / 255; foreground 0.29 / 0.07 / 260; primary 0.55 / 0.206 / 264; muted text 0.485 / 0.035 / 260. A deep blue values section gives the longer page rhythm.

## Typography
Manrope, served locally. Its open rounded forms, crisp structure and modest quirks bridge technical precision and approachability. Display type uses medium weight and close tracking; body text is relaxed, at 1.85–1.9 line height. Desktop hero type grows fluidly to 83px. Avoid gradient type and decorative monospace.

## Layout
1280px maximum content width with generous outer margins. Left-aligned hero copy, original airy blue ribbon artwork on the right. Services use a two-column introduction and disclosure list. The values statement changes the atmosphere with a blue field. Process steps and the final invitation have distinct spacing. Mobile stacks sections and keeps the main navigation visible.

## Components and interactions
Custom geometric Y brand mark with lowercase wordmark. Modest 7px corners on action links. Shadcn/Base UI accordion for service detail, native anchors for navigation and email. Clear focus rings, skip link, semantic section labels. A single short entrance sequence; all motion respects prefers-reduced-motion. No decorative continuous animation.

## Assets
public/images/yumani-ribbon.jpg is original generated artwork. Fonts are locally served Manrope weights with their OFL license. The favicon repeats the Y brand mark.
